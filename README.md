# Visita Virtual 3D Interativa ao Viana S+T+ARTS Center 🏢🎨

> Protótipo de visita virtual 3D interativa em tempo real ao Viana S+T+ARTS Center (antigo Matadouro Municipal de Viana do Castelo), desenvolvido no âmbito do projeto de curso em Engenharia de Computação Gráfica e Multimédia (ESTG/IPVC).

---

## 📋 Sobre o Projeto

O projeto consiste no desenvolvimento de uma aplicação interativa 3D que permite explorar o edifício do Viana S+T+ARTS Center, quer através de **exploração livre** em primeira pessoa, quer através de **visitas orientadas** acompanhadas por Pontos de Interesse (POIs) multimédia informativos.

* **Instituição:** Universidade Politécnica de Viana do Castelo — ESTG / UNIPVC
* **Curso:** Licenciatura em Engenharia de Computação Gráfica e Multimédia
* **Autores:** André Freitas e Keila Santos
* **Orientadores:** Pedro Moreira e João Nunes
* **Data Final de Projeto:** 17 de Janeiro de 2027

---

## 🛠️ Stack Tecnológica

* **Engine:** Unity (Universal Render Pipeline — URP)
* **Linguagem:** C#
* **Modelação 3D:** Blender
* **Packages & Bibliotecas:**
  * Unity Input System (suporte a Rato/Teclado, Ecrã Tátil e VR)
  * Cinemachine
  * DOTween (animações de UI)
  * ProBuilder

---

## 🚀 Funcionalidades Principais

- [x] **Exploração Livre:** Navegação em 1.ª pessoa pelo exterior e interior do edifício.
- [x] **Pontos de Interesse (POIs):** ~20 pontos com informação arquitetónica, funcional e estrutural (texto, imagem, vídeo e modelos 3D).
- [x] **Visita Orientada:** Percurso guiado por câmara de POI em POI.
- [x] **Multiplataforma:** *Builds* preparadas para **Android** (APK) e **Desktop** (Windows).
- [x] **Modo Imersivo:** Suporte concetual a dispositivos de Realidade Virtual (VR/3D).
